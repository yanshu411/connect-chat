CONNECTCHAT — FIREBASE + NETLIFY SETUP
====================================

This folder contains the static HTML/CSS/JavaScript + Firebase edition
of ConnectChat. It does not use Node.js, Socket.IO, PHP, or XAMPP.

1) VERIFY THE FIREBASE PROJECT
   Open firebase-config.js. It currently contains web Firebase settings
   for the project connect-chat-6dc01. Confirm this is your project.
   Otherwise copy the exact Firebase web app configuration from:
   Firebase Console > Project settings > Your apps > Web app.

   The Firebase web API key is a public identifier, not an admin key.
   Never upload a service-account JSON file or administrator credentials.

2) ENABLE LOGIN
   Firebase Console > Authentication > Sign-in method > Email/Password:
   Enable Email/Password authentication.

3) PUBLISH FIRESTORE RULES (REQUIRED)
   Firebase Console > Firestore Database > Rules:
   Copy everything in firestore.rules and click Publish.

   Uploading firestore.rules to GitHub or Netlify DOES NOT publish
   it to Firebase.

   Privacy note: the current rules allow signed-in users to discover
   other users' display names AND email addresses. Use test emails.

4) DEPLOY
   With a GitHub-connected Netlify project, use repo root as base,
   no build command, and publish directory:
      ConnectChat_Firebase_Netlify_Ready
   (The repository root netlify.toml has the same setting.)

   For manual Netlify Drop, drag this FOLDER directly, because it
   contains index.html at the top level.

5) AUTHORIZE YOUR LIVE DOMAIN
   Firebase Console > Authentication > Settings > Authorized domains:
   Add the actual hostname of the deployed Netlify site (no https://).

6) TEST WITH TWO USERS
   Register Account A in a normal browser and Account B in incognito.
   Find the other account under People, send a message and reply.
   Both browsers should update without needing a refresh.

7) RUN LOCALLY
   From the repository root:
      python -m http.server 5500 --directory ConnectChat_Firebase_Netlify_Ready
   Open: http://127.0.0.1:5500/

NOT INCLUDED
- Online/offline presence, typing indicators, read receipts, attachments
- End-to-end encryption
- Importing existing messages from the separate React/Node/SQLite edition

The complete documentation is in the repository root README.md.
