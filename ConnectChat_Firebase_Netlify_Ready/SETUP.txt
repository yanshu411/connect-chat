CONNECTCHAT — FIREBASE + NETLIFY SETUP
====================================
Project: connect-chat-6dc01

1. FIREBASE CONFIGURATION (REQUIRED)
   Open https://console.firebase.google.com/ > connect chat > Project settings (gear)
   > Your apps > Web app > SDK setup and configuration > Config.
   Open firebase-config.js in Notepad or VS Code.
   Replace PASTE_YOUR_API_KEY, PASTE_YOUR_MESSAGING_SENDER_ID, PASTE_YOUR_APP_ID
   with your exact values from Firebase Console. Verify authDomain and projectId.
   Save. Never paste a Firebase Admin SDK private key here.

2. AUTHENTICATION
   Firebase Console > Authentication > Sign-in method > Email/Password > Enable.
   Firebase Console > Authentication > Settings > Authorized domains:
   add your actual Netlify site domain (for example, my-site.netlify.app).

3. FIRESTORE SECURITY RULES (REQUIRED)
   Firebase Console > Firestore Database > Rules.
   Copy the entire contents of firestore.rules and paste it into the Rules editor.
   Click Publish. DO NOT use allow read, write: if true.
   Note: this app lets signed-in users discover other registered users' names and
   email addresses. Do not use real private email addresses for public discovery.

4. NETLIFY DEPLOYMENT
   After filling in firebase-config.js, upload this FOLDER (containing index.html,
   app.js, style.css, firebase-config.js) to Netlify's manual deploy drop area.
   Or ZIP the CONTENTS of this folder (not the enclosing folder) and deploy.
   Netlify will serve index.html directly. No build command or Node.js server needed.

5. TEST
   Register account A in your normal browser, and account B in an Incognito window.
   Select People, click the other account, and send a message.
   Both windows should show new messages in real time.

NOTES
- This is a rebuilt static Firebase version of the supplied React/Node/Socket.IO project.
- Email/password replaces username-only login; existing SQLite accounts/messages are NOT migrated.
- Real-time text messaging and profile editing are supported.
- Online presence, typing indicators, attachments, read receipts, and end-to-end encryption
  are NOT implemented. The UI does not claim these features.
- Firebase configuration alone does not make this app secure: publish firestore.rules.
- Firebase web API key is not an admin secret. Keep service account keys private.
- If a Firestore index error appears, follow the console link in the error to create it.
